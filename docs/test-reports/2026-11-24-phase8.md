## Known limits
- PDF and JSON report generation runs synchronously on the UI thread (fast for typical cases;
  very large multi-hundred-image cases can be evaluated for background worker export in Phase 9).
- ReportLab uses standard PDF Helvetica/Courier fonts; full Unicode glyphs outside Latin-1 (e.g.
  Arabic/CJK OCR output) may require an embedded TrueType font in a future hardening/i18n pass
  (JSON reports preserve full UTF-8 verbatim).
