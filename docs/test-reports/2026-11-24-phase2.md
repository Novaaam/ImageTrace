## Manual / visual
- `tools\screenshot.py` (native Windows platform, throwaway data root with **SYNTHETIC**-labelled
  cases): Dashboard, Cases, Settings, About and the New-case dialog, in light and dark themes.
- Problems found and fixed:
  - **Checkbox indicators were invisible** (the global stylesheet suppressed Fusion's box), so the
    required authorization tick and "Show archived" had no visible state. Added a styled indicator
    with SVG tick icons (`app/resources/check-*.svg`).
  - The details panel had grey form background blocks and clipped values on first render; the
    history list had a horizontal scrollbar. Fixed with a transparent form host, word wrap, no
    horizontal scrolling and a minimum width.
- `start.bat` was launched against a throwaway data root (`IMAGETRACE_DATA_ROOT`): the app
  started under `pythonw.exe`, created the DB and wrote the log ("starting", "migrated to schema v1").
- `requirements.bat` (environment already set up): all pinned packages satisfied, `pip check`
  OK, PySide6 import OK, exit 0. A bad argument prints usage and exits 2. No `pip-*` temp folders
  were created on C:.

## Bugs caught by tests during development
- `verify_backup` used `str.capitalize()`, which lowercased "SHA-256" and "OK" in the message.
  Fixed.
- One test assertion was wrong (expected no match for a literal `%` that really was in the notes).
  The test was corrected; the code behaved correctly.

## Performance
- Main window start-up: 0.27–0.44 s (profiled). Most of it is the first migration commit
  (~0.17 s, disk sync) and applying the stylesheet (~0.13 s).
- The test suite took 86 s because every window re-applied an identical global stylesheet,
  re-polishing every live widget. `apply_theme` now skips identical sheets, and the suite takes 36 s.
