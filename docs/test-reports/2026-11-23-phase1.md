# Test Report: Phase 1 GUI shell

**Date:** 2026-11-23 · **Environment:** Windows 10 Pro 19045, Python 3.12.10, PySide6 6.12.0,
pytest 9.2.0, pytest-qt 4.5.0, ruff 0.17.6

Coverage by area:
- **Navigation:** all 7 sections listed in order; mouse click on each; Ctrl+1…Ctrl+7 shortcuts;
  arrow-key navigation in the sidebar.
- **No fake data:** every label and placeholder is scanned for lorem/demo/sample names,
  SHA-256-looking strings and coordinate-looking pairs.
- **Empty states:** the dashboard's empty states are honest, and each placeholder page names the
  phase it arrives in.
- **Top bar and storage:** active case "none", the storage location is shown, and search is
  disabled until Phase 2.
- **Theme:** the change applies and persists to `data/config/settings.json`, and is restored
  after a restart.
- **Missing data root:** shows an error state, and changing the theme doesn't create the missing
  directory (no silent fallback).
- **Storage checks:** missing, not-a-directory and low-space detection; `format_bytes`.
- **Settings file:** defaults, round-trip, corrupt file (gives defaults and the file is
  preserved), sanitising unknown or invalid values, atomic write with no temp leftovers.
- **Temp location:** pytest temp lives on the project drive (`--basetemp=data/temp/pytest`).

## Manual / visual
- `tools\screenshot.py` rendered Dashboard, Cases, Settings and About in light and dark themes,
  using both the offscreen and native Windows platforms.
- Checked: readable contrast in both themes, a clear focus indicator on the selected sidebar item,
  status colours (green OK / amber warning), no clipped text in the tool-status card at 1200×760.
- Problem found and fixed: the tool-status card used a two-column form that wrapped values one
  word per line. It's now a single-column list.
- Note: the offscreen platform needs `QT_QPA_FONTDIR`. Without it, all text renders as boxes
  (test-tooling issue only).

## Not covered
- Real high-DPI scaling and Windows dark-mode auto-detection ("System" theme) on a live display.
- Screen-reader checks (accessible names are set; not tested with Narrator).
